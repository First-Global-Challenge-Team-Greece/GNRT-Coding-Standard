# GNRT Coding Standard

## FGC Team Greece

Το **GNRT Coding Standard** αποτελεί το κοινό πρότυπο ανάπτυξης κώδικα της ομάδας προγραμματισμού της **FGC Team Greece**.

Στόχος του είναι να εξασφαλίζει ότι όλα τα μέλη της ομάδας αναπτύσσουν κώδικα με κοινή δομή, κοινές πρακτικές και σταθερή ποιότητα, ώστε ο κώδικας να είναι εύκολος στην κατανόηση, τη συντήρηση και τη συνεργασία μεταξύ των μελών.

## Τι περιλαμβάνει

Το Coding Standard καθορίζει τις βασικές πρακτικές που ακολουθεί η ομάδα σχετικά με:

* Προγραμματιστική γλώσσα και εργαλεία ανάπτυξης
* FTC SDK και Android Studio / Gradle
* Git και GitHub workflow
* Branches και commit messages
* Pull Requests και Code Reviews
* Δομή των projects και packages
* `HardwareMapConfig` και configuration files
* Naming conventions
* Java coding style
* Legacy code
* Deployment διαδικασίες
* Εξωτερικές βιβλιοθήκες
* Κοινές πρακτικές συνεργασίας και ownership του κώδικα

## Βασικές αρχές

Η ομάδα ακολουθεί ένα κοινό development workflow:

**Develop → Commit → Pull Request → Review → Merge**

Κάθε αλλαγή στον κώδικα πρέπει να είναι κατανοητή, τεκμηριωμένη και να ακολουθεί τα κοινά standards της ομάδας.

Ιδιαίτερη έμφαση δίνεται στη:

* συνέπεια του κώδικα,
* καθαρή αρχιτεκτονική,
* σωστή χρήση του Git,
* αναγνωσιμότητα,
* συνεργασία μεταξύ των developers,
* διατήρηση ενός ενιαίου codebase.

## Team Philosophy

> **Write code that the next teammate can understand, maintain and improve.**

Το Coding Standard δεν έχει σκοπό να περιορίσει τη δημιουργικότητα των developers. Σκοπός του είναι να δημιουργήσει ένα κοινό πλαίσιο μέσα στο οποίο όλοι μπορούν να συνεργάζονται αποτελεσματικά.
